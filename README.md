Hi, I’m Erik van der Bas — Lead Developer and co-owner of Studio Lemon 🍋

For over 15 years, WordPress has been my playground. What started as building websites evolved into designing better ways to build them. At Studio Lemon, my day-to-day work consists of creating digital products based on our in-house stack called wp-lemon and maintaining wp-lemon and all supporting tools that we use to have a smooth development experience.

Open source is where I learn, experiment, and give back to the community that taught me so much.

I believe good code is understanable, well documentated and above all, a joy to work with.
